# xRocket Exchange API

Telegram-native centralized crypto exchange (CEX) developer program exposing a REST Exchange API for trading and market data (with a WebSocket stream) and a REST Pay API for payments, cheques, invoices, transfers and withdrawals. Bearer-token authenticated with public read endpoints and Swagger/OpenAPI contracts.

## APIs

- **xRocket Exchange API** — REST API for creating/canceling market/limit orders, retrieving order books, tracking pair rates, executing trades and querying conversion rates, plus a documented WebSocket stream for real-time market data, account updates, balances and order events. (`https://exchange.api.xrocket.exchange`)
- **xRocket Pay API** — REST API (v2) to manage cheques, transfers, invoices, withdrawal links, withdrawals, mass transfers and query rates and currencies. (`https://pay.api.xrocket.exchange`)

> Two conventional REST APIs (Exchange and Pay v2), both Bearer-token authenticated with public read endpoints and publicly served Swagger/OpenAPI at their /api/docs endpoints. WebSocket stream (wss://exchange.api.xrocket.tg/ws) is documented in prose only, no AsyncAPI. No official Postman collection or GraphQL. No agent-native surfaces: no MCP server, no llms.txt, no published agent skills. Community SDKs (xrocket-pay-ts-sdk, milkpay-xrocket, etc.) are conventional REST wrappers, not agent-native. Trade API v1 and Pay API v1 are deprecated.
