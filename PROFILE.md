# xRocket Pay API

Payments API of xRocket, a Telegram-based crypto wallet/exchange. Lets developers integrate crypto payment features (cheques, transfers, invoices, withdrawals) via a Bearer-authenticated REST API with production and testnet environments.

## APIs

- **xRocket Pay REST API** — Bearer-authenticated REST API for crypto payments: cheques, transfers, invoices, withdrawals, mass transfers, app-info, currencies and rates. Endpoints served under /api/v1/. (`https://pay.api.xrocket.exchange/api/v1`)

> Documented Bearer-authenticated REST API with production (https://pay.api.xrocket.exchange/) and testnet (https://pay.api.testnet.xrocket.exchange/) base URLs.
